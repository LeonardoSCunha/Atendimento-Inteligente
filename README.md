# Atendimento-Inteligente
Atendimento e agendamento com bot inteligente
# Problema
Uma empresa recebe mais de 500 mensagens por dia de clientes, com problemas variando entre: reclamações, cobranças indevidas, dificuldade de acesso e cancelamento
# Situação
Atualmente uma pessoa é designada para o atendimento e envio diario desssas mensagens para o departamento correto
# Solução 
Desenvolver um bot nteligente para  ler a mensagem do clientes, enviar a um servidor onde a Inteligencia artificial irá tratar a mensagem e direcionar para o departamento correspondente, assim como sugerir um tipo de mensagem de retorno ao cliente, ela deve indentificar o assunto, classificar o atendimento e determinar nivel de atendimento. Deve mostrar a mensagem em uma tela para evisão.
# Ferramentas
Um banco de dados para armazenar a informação
JSON para formato dos dados
Modelo local de Inteligencia artificial
integração com API
Dashboard
Roolback para evitasr perda de mensagem
Validação de acertos do modelo de IA
# Objetivo
Integração de API
Inteligencia artificial
Banco de dados
Tratamnento de erros
Avaliação de resultados
Regras de negocios
